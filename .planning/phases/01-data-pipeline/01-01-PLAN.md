## Shared Output Contract (binding on Plans 02-05)

**TeamOutput** (one entry in `teams.json`'s `teams` array, produced by `transformTeam` + the vendor step): `id` (number), `school` (string), `mascot` (string | null), `abbreviation` (string | null), `conference` (string, required non-null), `classification` (string | null), `color` (string, required non-null), `alternateColor` (string, required non-null), `logo` (string — always populated: `/logos/{id}.png` on success or `/logos/placeholder.svg` on fallback).

`teams.json` top level: `{ season: number, teams: TeamOutput[] }`

**GameOutput** (one entry in `games.json`'s `games` array, produced by `transformGame`): `id` (number), `week` (number), `seasonType` (string — raw CFBD value, verbatim), `homeId` (number), `homeTeam` (string), `awayId` (number), `awayTeam` (string), `conferenceGame` (boolean — raw CFBD value, verbatim), `neutralSite` (boolean — raw CFBD value, verbatim). No derived "is championship" boolean is added at this phase — `seasonType` + `conferenceGame` are the raw signal; deriving a composite flag is explicitly deferred to Phase 5 per RESEARCH.md Open Question #1 (unconfirmed against live data until Plan 05 Task 2).

`games.json` top level: `{ season: number, scheduleHash: string (8 lowercase hex chars), games: GameOutput[] }`

**CoverageReport** (`coverage.json`): `{ season: number, generatedAt: string (ISO timestamp), teams: Array<{ id: number, school: string, requiredFields: 'pass' | 'fail', missingFields: string[], logo: 'pass' | 'missing' | 'download-failed' }>, summary: { totalTeams: number, requiredFieldFailures: number, logosVendored: number, logosMissing: number } }`
