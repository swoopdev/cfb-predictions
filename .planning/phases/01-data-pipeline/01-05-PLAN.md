## Shared Output Contract (binding — matches Plans 01/03/04 exactly)

**TeamOutput** (`teams.json` entry): `id`, `school`, `mascot`, `abbreviation`, `conference`, `classification`, `color`, `alternateColor` (all from `transformTeam`), plus `logo` — `` `/logos/${id}.png` `` when `vendorLogo` returns `status: 'ok'`, else `'/logos/placeholder.svg'`.

**GameOutput** (`games.json` entry): the 9 fields returned verbatim by `transformGame` — `id`, `week`, `seasonType`, `homeId`, `homeTeam`, `awayId`, `awayTeam`, `conferenceGame`, `neutralSite`. No derived "is championship" boolean.

`teams.json`: `{ season, teams: TeamOutput[] }`. `games.json`: `{ season, scheduleHash, games: GameOutput[] }`. `coverage.json`: the object returned by `buildCoverageReport`.
</context>

If `failures.length > 0`, `console.error(JSON.stringify(failures, null, 2))` (safe — contains only team ids and field names, no secrets) and `process.exit(1)` — this exit must occur before any `writeFile` call anywhere in the file, so nothing is committed on a hard-fail (D-09). For each raw team: call `transformTeam(raw)` for the core fields, then `await vendorLogo(team.id, team.logos?.[0])`; assemble the final `TeamOutput` by spreading the core fields plus `logo: result.status === 'ok' ? result.path : '/logos/placeholder.svg'`; also collect `{ id: team.id, school: team.school, requiredFieldsOk: true, missingFields: [], logoStatus: result.status }` per team for the coverage report (requiredFieldsOk is always true here since the hard-fail branch above already returned on any false case).

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
