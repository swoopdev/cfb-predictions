## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Browser URL -> render logic | `route.params.week` is technically user/URL-controllable input (a visitor can hand-edit `/week/abc` or `/week/999`) even though the data it filters is public, static JSON |
| Static JSON (`public/data/2026/*.json`) -> app | Committed, build-time data — not attacker-controlled, but the fetch/parse path must degrade gracefully if the deploy is missing or corrupt (UI-SPEC error row) |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | `route.params.week` (e.g. `/week/abc`, `/week/999`, `/week/-1`) | medium | mitigate | `Number(route.params.week)` coercion means a non-numeric or out-of-range week simply matches zero games (`g.week === NaN` or `=== 999` never true) — no array-index access, no crash; the resulting empty grid is the same safe path as any other empty week. |
| T-02-02 | Denial of Service | `useTeams()`/`useGames()` error/missing-deploy path | low | mitigate | Task 3's `determineLoadState`/error branch renders a controlled full-page error state instead of letting an unhandled promise rejection or `undefined.filter()` crash the app. |
| T-02-03 | Information Disclosure | Schedule/team JSON payload | low | accept | All data is public 2026 schedule information; no PII, no secrets, no CFBD API key ever reaches `app/` (the key lives only in Phase 1's fetch-script `.env`). |

No `T-02-SC` row: this plan installs no new packages (confirmed by RESEARCH.md's Package Legitimacy Audit — "not applicable, no npm install occurs in this phase's plan").
