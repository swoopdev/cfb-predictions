## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-06 | Tampering | `?conf=<arbitrary string>` / `?team=<arbitrary string>` (e.g. `?conf=<script>alert(1)</script>`, `?team=99999999`) | medium | mitigate | Task 1's `sanitizeConfParam`/`sanitizeTeamParam` reject any value not present in the known conference list / loaded team-id set and fall back to unfiltered — no unsanitized query value ever reaches `filterGames` or a template binding. |
| T-02-07 | Denial of Service | Malformed `team` param crashing `Number()`/array-index logic | low | mitigate | `Number.isSafeInteger` guard inside `sanitizeTeamParam` before any `teamsById.has()` lookup — a non-numeric or absurdly large string never reaches an unguarded numeric comparison. |
| T-02-08 | Tampering (reflected content) | Team/conference names rendered from filter selections | low | accept | No `v-html` is used anywhere in this plan's components — Vue's default `{{ }}` interpolation auto-escapes, and the sanitize functions further constrain values to a known-good set before they're ever bound to a template. |

No `T-02-SC` row: this plan installs no new packages.
