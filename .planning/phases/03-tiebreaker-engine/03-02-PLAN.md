  <behavior>
    - evaluateNextHighestPlacedCommonOpponent walks the frozen baseOrdering from index 0 downward. At each bucket, it identifies which of that bucket's teams are common opponents of every tied team. A bucket with zero qualifying common opponents is skipped entirely (never contributes a 0/0 comparison) -- the walk continues to the next bucket. The first bucket with 1+ qualifying opponents is "the next highest-placed common opponent." If that bucket has more than one team (a raw-standings tie), every tied team's win percentage is computed against the WHOLE bucket collectively (summed wins / summed games against every team in the bucket), never against individual opponents one at a time. This function is conference-agnostic and is dispatched identically for all four conferences: the Big 12's use of this collective-bucket treatment is primary-source-confirmed (D-05/D-06), while the SEC's and Big Ten's use of the identical treatment is a documented extrapolation (D-13) since neither conference's own tiebreaker document contains the Big 12's specific collective-bucket sentence.
    - evaluateTotalWins partitions by each tied team's value in the supplied overallWinCounts map (already FCS-capped by Plan 03-01's deriveOverallWinCount) and throws a descriptive Error if overallWinCounts is undefined (a programmer-error guard -- only Big 12's CONFERENCE_RULES entry should ever include this step).
  </behavior>
