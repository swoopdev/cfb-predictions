  <name>Task 1: Implement computeStandings pure function for all P4 conferences (STAND-01, STAND-03)</name>
  <files>shared/domain/standings/computeStandings.ts, shared/types/standings.ts</files>
  <action>
    Create a pure TypeScript function `computeStandings(games: Game[], teams: Team[], picks: Record<number, number>, resolvedTiebreaker: TiebreakerResult)` in `shared/domain/standings/` that computes standings for all P4 conferences (SEC, Big Ten, Big 12, ACC). Function must be zero Vue/Nuxt imports per PROJECT.md's DRY constraint.

    **Logic:**
    1. Filter teams to only P4 conferences (check team.conference against ["SEC", "Big Ten", "Big 12", "ACC"])
    2. For each P4 conference:
       - Initialize a map of `{ teamId: { teamName, overallWins, overallLosses, confWins, confLosses } }`
       - For each game in the slate:
         - If either home or away team is not in P4, skip (per STAND scope)
         - If both teams are in the same conference (conference game):
           - If picks[gameId] exists and equals homeId: homeId +1 conf win, awayId +1 conf loss
           - If picks[gameId] exists and equals awayId: awayId +1 conf win, homeId +1 conf loss
           - Regardless of conference game: apply the same logic to overall records
         - If teams are in different conferences (non-conference game):
           - Only update overall records, not conference records
       - Create `StandingsTeam[]` array: each team with `{ id, school, conference, overallRecord: {w, l}, confRecord: {w, l} }`
       - Apply tiebreaker ranking (see below)
       - Sort by (conference record descending, then by tiebreaker rank, then by alphabetical name)
    3. Apply tiebreaker ranking per D-11/D-13:
       - For each conference, call `resolveConferenceChampionship(games, teams, picks)` from Phase 3 to get `Resolved(order) | NeedsUserInput(tiedTeams, reason)`
       - If Resolved: use the returned order to rank teams
       - If NeedsUserInput: flag the tied teams with the same rank number (standard sports tie-breaking: if 3 teams are tied at 6-2, all show rank "2"; next team is rank "5")
    4. Return object: `{ [confName]: StandingsTeam[] }` for all 4 conferences

    **Type definitions in shared/types/standings.ts:**
    ```typescript
    export interface ConferenceRecord {
      wins: number;
      losses: number;
    }

    export interface StandingsTeam {
      id: number;
      school: string;
      conference: string;
      overallRecord: ConferenceRecord;
      confRecord: ConferenceRecord;
      rank: number;
      isTied: boolean; // true if multiple teams share this rank
    }

    export type StandingsResult = {
      [confName: string]: StandingsTeam[];
    }
    ```

    **Constraints:**
    - Do NOT mutate input arrays/objects
    - Do NOT call Vue reactive functions (computed, ref, etc.)
    - Conference game determination: use `game.conferenceGame` flag from Phase 1, not computed from team conferences
    - Non-FBS opponents (127 FCS games): if a game has homeId or awayId not in teams.json, handle gracefully — look up only the teams that exist, apply logic only to those
  </action>

  </verify>
