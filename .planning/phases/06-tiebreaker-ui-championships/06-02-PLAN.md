## Phase Goal

> **ROADMAP goal (verbatim):** Users can see exactly how each conference's championship matchup was determined, see a fully ranked 1..N conference table wherever the tiebreaker procedure can determine an order, and resolve any tie the engine can't settle on its own.

**This plan's slice.** The engine stops answering "who are the two championship participants?" and starts answering "what is the whole conference's order, and where does the procedure run out?" Nothing user-visible changes yet — a transitional derived view keeps the existing display working unchanged — but this is the shared groundwork every later slice reads from, and it closes the defect that would otherwise turn 19.2% of displayed ranks into a database-id sort wearing a "decided by tiebreaker" badge.

<objective>
Extend the tiebreaker engine from two seeds to 1..N and repair the third logged defect in the same change, because they are two halves of one edit.

D-03 says extend the commit-and-restart loop past two slots; the `alreadyCommitted` mechanism already works this way. D-04 defect 2 says the engine can contradict itself between seed 1 and seed 2 because an unseparated multi-team bucket is emitted in raw team-id order. 06-RESEARCH.md Pattern 1 is explicit that doing the loop without that repair "propagates the defect to every rank in the table instead of hiding it in one shared rank" — and D-10(a) would then attach a "decided by tiebreaker" marker to a rank decided by CFBD database id, turning a silent defect into an affirmative false claim.

The loop also structurally eliminates the contradiction class rather than one instance: because a single ordered sequence produces both seeds, they cannot disagree.

Purpose: PROJECT.md — "if the standings math or the tiebreaker resolution is wrong, nothing else about the app matters."
Output: `RankGroup` / `ConferenceRanking`, `resolveConferenceRanking`, `championshipFor`, and three committed test files including the reproducible N-seed measurement.
</objective>

## Target type shapes (binding contract for Plans 03-07)

- `RankGroupResolution` — a string union: `'sole-candidate' | 'tiebreaker' | 'manual' | 'unresolved'`.

- `championshipFor(ranking)` returns `{ seed1?: RankGroup, seed2?: RankGroup }`.
