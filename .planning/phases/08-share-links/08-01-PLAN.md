## Phase Goal

> **ROADMAP goal (verbatim):** Users can share a scenario via a URL that opens with those exact picks applied, without ever clobbering the visitor's own picks.

**Planner note (MVP mode):** this ROADMAP `**Goal**:` line is outcome-shaped but not literally in the `As a … I want to … so that …` user-story form MVP mode expects (no explicit user role, no explicit "so that" outcome clause) -- the same format gap Phase 7's planner noted and handled the same way. Reproduced verbatim above rather than rewritten, per the "do not invent a story" rule. A synthesized form, offered only as context: *as a user who has built out a scenario, I want to send someone a link that opens with my exact picks, so that I can show them my prediction without them logging in or my own picks being touched.* Run `/gsd mvp-phase 8` first if the canonical ROADMAP form is wanted before continuing.

**This plan's slice.** Nothing user-visible ships in this plan -- it is the load-bearing binary codec and untrusted-input validation boundary every later plan in this phase depends on, mirroring Phase 7 Plan 01's role. After this plan, a scenario's picks and manual tiebreaker overrides can be losslessly packed into a short URL-safe string and unpacked back out, with every malformed or hostile input degrading to a typed, safe result instead of corrupting data or crashing.
