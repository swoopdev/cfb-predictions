## Phase Goal

> **ROADMAP goal (verbatim):** Users can share a scenario via a URL that opens with those exact picks applied, without ever clobbering the visitor's own picks.

**Planner note (MVP mode):** see Plan 08-01's Phase Goal section for the full discrepancy note on this ROADMAP line's format and the synthesized user-story equivalent; not repeated here.

**This plan's slice.** After this plan, a user can click Share on any scenario -- active or not, with zero picks or a full season's worth -- and get back a working, copyable URL that a recipient could open (Plan 08-03 makes that URL actually DO something when opened; this plan only proves it can be correctly generated and copied).

<objective>
Add a "Share" action to `ScenarioSwitcher.vue`'s per-row actions, a new `ShareLinkModal.vue` component that displays and copies the generated URL, and `handleShare` wiring in `week/[week].vue` that reads a scenario's raw stored picks/manual decisions (following Phase 7's established non-active-scenario access pattern) and encodes them via Plan 08-01's `encodeShareLink`.

Purpose: this is SHARE-01's entire user-facing surface -- the only way a share link ever comes into existence. Every byte of the actual encoding risk was already retired in Plan 08-01; this plan is pure UI wiring around it, following Phase 7's `DeleteScenarioModal.vue`/`ScenarioSwitcher.vue` patterns exactly so it introduces zero new interaction idioms.
Output: `ShareLinkModal.vue`, an extended `ScenarioSwitcher.vue`, and `week/[week].vue`'s `handleShare` -- together, a user can generate and copy a share link for any scenario in two clicks.
</objective>
